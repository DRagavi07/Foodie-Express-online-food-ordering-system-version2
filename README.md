# 🍔 Foodie Express – Online Food Ordering System

## 📌 Project Overview
Foodie Express is a user-friendly online food ordering application developed using Python and Streamlit. It allows customers to browse food items, add items to their cart, place orders, and track their order status.

This project is based on an existing GitHub project with additional modifications and features.

## 🎯 Objectives
- To develop a user-friendly online food ordering application.
- To provide easy access to food menu items.
- To allow customers to place food orders.
- To provide separate admin login access.
- To enable customers to track their orders.
- To maintain customer order history.
- To provide a demo payment facility.
- To improve order management.

## ✨ Key Features
- User Registration and Login
- Food Menu with Multiple Items
- Shopping Cart
- Quantity Management
- Order Placement
- Order Tracking
- Order Status Updates
- Order History
- Admin Login
- Admin Order Management
- Demo Payment Facility

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Frontend:** Streamlit
- **Database:** SQLite
- **Library:** Pandas

## 👥 User Modules

### Customer Module
- Register and Login
- View Food Menu
- Add Food Items to Cart
- Manage Quantity
- Place Orders
- Track Order Status
- View Order History
- Update Account Details

### Admin Module
- Admin Login
- View Customer Orders
- View Order Details
- Update Order Status

## 📊 Order Status
- Pending
- Confirmed
- Preparing
- Out for Delivery
- Delivered

## 💳 Payment
This application provides a demo payment facility. No real money transactions are processed.

## ⚙️ Installation and Execution

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Open the project folder:

```bash
cd Foodie-Express
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python -m streamlit run main.py
```
